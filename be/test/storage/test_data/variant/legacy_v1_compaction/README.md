# Legacy V1 VARIANT compaction fixture

`segment_0.dat` is an immutable segment written by the removed V1 VARIANT
writer. It must not be regenerated by the current V2 writer.

- Source revision: `fb0b0c5358e341286c30d7af67a6b996a9d50b1d`
- Generator path: the source revision's
  `VariantColumnWriterReaderTest::create_variant_rowset`, invoked by a temporary
  fixture-generation test with the rows described below
- SHA-256: `0d437cf92471cbb13ee5ee95298d3879e4abf8b0adb9e68a7d35ad2ec811e041`
- Rows: 8
- Tablet column: non-nullable `VARIANT`, unique id 1, maximum 2 materialized
  subcolumns

The generator writes the rows through the legacy V1 `RowsetWriter` and then
opens the resulting segment through `BetaRowset::load_segments`, which verifies
the persisted footer and trailer. The same row shape was also checked by the
source revision's V1/V2 writer compatibility test to contain both materialized
and sparse subcolumns and to reconstruct the complete root values. The fixture
includes objects, arrays, scalar roots, an empty object, a JSON-null leaf, and a
root JSON null.

To reproduce it, check out the source revision in an isolated worktree, preserve
the generator's test directory during teardown, and run the generator through
`run-be-ut.sh` with the V1 parameter. Verify the SHA-256 before replacing this
file.
