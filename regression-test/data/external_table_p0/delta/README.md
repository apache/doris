# Official Delta Golden Tables

`golden-tables.zip` contains the fixtures from
[`delta-io/delta`, commit `9cb15d26156ac42e646e69d26652976fdb72f8df`](https://github.com/delta-io/delta/tree/9cb15d26156ac42e646e69d26652976fdb72f8df/connectors/golden-tables/src/main/resources/golden).
The 753 fixture files are copied byte for byte. Hadoop `.crc` files are omitted;
the upstream Apache 2.0 license is included as `UPSTREAM_LICENSE.txt`.
ZIP timestamps and file modes are fixed for reproducibility. The manifest pins
the archive's SHA-256. No upstream code is loaded or executed by the regression.

The suite uses the real Delta catalog, FE snapshot planning, DeltaTableReader and
V2 Parquet reader. It extracts fixtures under the worktree's `output/`, retains
them after testing, and requires FE and BE to share that local filesystem.

`golden-tables.json` enumerates all 108 Delta table directories, the non-Delta
directory negative case, and 126 earlier versions. It records explicit expected
errors for unsupported features, invalid metadata, missing files and historical
schema/partition evolution. These cases are not counted as successful reads.
Missing committed files are checked with both scanners, including when the BE's
general missing-file ignore setting is enabled.

The initial outputs were independently checked with Apache Spark 4.1.1 and Delta
Spark 4.3.1, in UTC. Normal results are compared as multisets of typed rows,
preserving duplicates, null ancestors and nested values. The three million-row
decimal dictionary tables and the 99,998-row decimal table instead verify the
complete unique ID domain and the generator's decimal expressions on every row.
The corresponding Spark queries return zero expression violations. Generator
definitions are in upstream `GoldenTables.scala`; official reader expectations
are also in `DeltaTableReadsSuite.scala`, `DeletionVectorSuite.scala` and
`LogReplaySuite.scala` at the same pinned commit.

Run against a local worktree cluster:

```bash
DORIS_HOME="$PWD" ./run-regression-test.sh --run \
    -d external_table_p0/delta -s test_native_delta_golden_tables
```

The `.out` file is generated by the standard regression runner and then checked
in normal comparison mode. When updating fixtures, repeat the independent
reference comparison before regenerating it with `-genOut`.
